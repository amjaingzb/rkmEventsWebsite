# Halasuru Event Registration

Registration site for Swami Sarvapriyananda's visit to Ramakrishna Math
Halasuru (31 Oct 2026).

All project documentation — architecture, setup steps, current status/next
steps, and the backlog — lives in [`docs/home.md`](docs/home.md). Start there.

Quick start once `.env.local` is filled in (see `docs/setup.md`):

```
npm install
npm run dev
```
