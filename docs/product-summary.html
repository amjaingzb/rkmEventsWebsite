Payments & Seat Guarantee

the core promise

The one invariant the whole system is built to protect: exactly 500 seats are ever confirmed, no matter how many people submit at once.

UPI payment, manually verified
Registrant pays via UPI QR/deep-link; a volunteer confirms the reference and one click issues the seat.
Live
Race-safe seat allocation
Seats are claimed by a single atomic database operation at the moment of verification — stress-tested with 20 simultaneous registrations, zero overselling.
Live
Automated checkout via PhonePe
Pay by any UPI app, card or netbanking; seat is claimed and the ticket sent automatically the moment payment clears — no volunteer needed.
Sandbox demo
Live payment-mode switch
Admin toggles the whole site between manual-verification and automated-PhonePe mode in one click, no redeploy.
Live

Where it goes next

Door check-in app — scan the ticket QR to mark attendance in real time; the ticket format is already built for it.
Waitlist re-invite — a one-click way to pull from the waitlist if a larger venue becomes available.
Mobile-friendly admin dashboard — the same controls, redesigned to work comfortably from a phone.
Tiered admin access — a lighter-weight role for volunteers who only need to edit site content, not registrant data.
PhonePe going live — the same automated checkout already working in sandbox, switched on with a real merchant account.
Reusable for other Math events — the platform is already built so a future event just needs its own venue/date/seat-cap/FAQ configuration, not a rebuild.
